# Fi — TNT FIGHT LAB Combat Collection

Catálogo digital oficial para **TNT FIGHT LAB × AFFINITY BJJ** — *The Elements Combat Collection (2026)*.

Una experiencia web de alta gama inspirada en la dirección visual de marcas deportivas líderes (Gymshark), diseñada específicamente para indumentaria de combate y Jiu-Jitsu Brasileño (BJJ).

---

## 🥋 Características

- **Diseño Element-First:** Catálogo organizado por los 5 elementos marciales (Agua 🌊, Aire 💨, Fuego 🔥, Tierra 🌿 y Avatar ☯️).
- **Selector Dinámico de Colorways:** Swatches de combinaciones de color interactivos (Negro/Blanco, Azul, Morado, Marrón, Rojo, Rosa) que actualizan el mockup en tiempo real sin recargar la página.
- **Inspector Modal HD:** Visor de detalle en alta resolución con zoom interactivo, navegación por teclado y ficha técnica.
- **100% Responsivo:** Optimizado para smartphones, tablets y pantallas de escritorio con drawer deslizable de filtros.
- **Barra Lateral de Filtros & Orden:** Filtrado por género (Hombre / Mujer), elemento, color, ajuste y disciplina marcial.

---

## 🛠️ Stack Tecnológico

- **Framework:** React 18 + TypeScript + Vite
- **Estilos:** Tailwind CSS + Google Fonts (Bebas Neue, Montserrat, Inter)
- **Íconos:** Lucide React
- **Package Manager:** pnpm

---

## 🚀 Instalación y Desarrollo Local

```bash
# Instalar dependencias
pnpm install

# Iniciar servidor de desarrollo en localhost:5174
pnpm run dev

# Compilar para producción
pnpm run build
```
